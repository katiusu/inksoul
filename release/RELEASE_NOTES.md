# InkSoul 0.1.0 版本说明

发布日期：2026-10-31｜包：`inksoul-0.1.0-py3-none-any.whl`（71 KB）

## 这是什么

面向 AI Agent 的中文文学创作增强插件：句法指纹诊断 + 文体分布分析 + 生成期文体控制 + 局部修订。
不输出 AI 概率，不输出综合评分。

## 本版包含

| 模块 | 内容 |
|---|---|
| 文本处理 | 段落/句子/小句切分、jieba 分词与词性、归一符号体系（含 `把/被/只是/没有` 消歧） |
| 句法指纹 | 加权编辑距离、星形结构簇、骨架复用率、模式熵、J1–J3 修辞判据、体裁基线 |
| 分布分析 | 句法多样性、文体（TTR/句长/对话比/情绪词）、叙事（视角/场景/对话节拍/信息密度） |
| 审阅 | 四类问题（机械复用/相邻雷同/句首重复/情绪直陈），带证据与建议，**无总分** |
| 生成 | OpenAI 兼容客户端（重试/脱敏）、文体规划、多候选择稿、局部修订、复核 |
| 接口 | Python API、CLI 6 个子命令、JSON 报告（`inksoul/1`） |
| 文档 | 研究报告 3 篇 + 设计/使用文档 9 篇 + 2 个 Skill |

## 验证状态

- 自动化测试：**77 项通过**（`python3 -m unittest discover -s tests -p "test_*.py" -t .`）
- 低资源：无 GPU、纯 CPU、无网络可分析；缺 jieba 时 `doctor` exit 2 并给中文提示
- wheel 安装：已用 `pip install --target` 实测 44 个文件、`inksoul doctor` 正常
- **未验证**：真实 DeepSeek API 的端到端生成（本机无 Key）。

## 已知问题（详见 docs/limitations.md）

1. 所有阈值未标定，输出是「线索」不是「判定」。
2. 默认无依存句法，兼语/连动/话题链判断为低置信。
3. 存在漏报：`suspects=0` 而 `reuse_rate=100%` 的模板文本（实验 F 已记录）。
4. 情绪/修辞识别为词表法，覆盖率有限。

## 升级注意

- `NORM_TABLE_VERSION` 变更会使旧基线失效，需 `inksoul baseline build` 重建。
- 配置文件未知字段会直接报错（防拼写静默失效），升级后若加了字段请对照 `docs/API_SPEC.md`。
