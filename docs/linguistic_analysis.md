# 中文文学 AI 文风的语言学分析与问题分类

> 版本：v1（研究阶段）
> 定位：本文不是"AI 检测器说明书"，而是**把"机械感"这个模糊印象拆成可测量、可归因、可干预的语言学变量**。凡本文断言，均标注证据状态：`[E]` 有文献实证支撑、`[H]` 本项目提出的可检验假说、`[K]` 语言学常识/共识（需按语体具体化）。
> 配套文档：`literature_review.md`（文献与证据）、`syntax_fingerprint.md`（句法指纹实现）、`generation_strategy.md`（干预策略）。

## 0. 方法与边界

### 0.1 三条方法论红线

1. **相关 ≠ 因果**。"某特征在 AI 文本中出现更多"只说明该特征可作为**测量信号**，不说明它由模型架构造成。Reinhart 等（2025）在 Biber 特征体系上发现 LLM 与人类存在系统性差异，且差异从小模型到大模型**持续存在**、在 instruct 模型上**更大**（`[E]` reinhart2025llmstyle）；这只能推出"特征差异与模型训练/对齐流程相关"，不能推出"模型一定因此产生 A 特征"。Juzek & Ward（2024）对 "delve" 类词汇过度表征的溯源同样谨慎：他们**未能**找到架构、算法、训练数据导致该现象的证据，模型对比与在线实验**与 RLHF 起作用相容**，但被试对 "delve" 类词的反应与其他焦点词并不一致（`[E]` juzek2024delve）。
2. **重复 ≠ AI**。人类文学有大量受体裁约束的重复（章回体套语、排比、反复、顶针、网文打脸节奏）。把重复直接判为 AI 特征是典型的选择性归因错误。任何以重复为核心的指标，都必须**以体裁基线为条件**（见 §5 与 `syntax_fingerprint.md` §6）。
3. **可读 ≠ 好**。Porter & Machery（2024）发现非专家读者识别 AI 诗歌的准确率低于随机水平（46.6%，χ²(1, N=16,340)=75.13, p<0.0001），且**更倾向于把 AI 诗判为人类作品**，AI 诗在"节奏/美感"等维度评分更高；作者解释为 AI 诗更简单、更易被非专家理解（`[E]` porter2024poetry）。这个结果同时否证两件事：①"人类能凭直觉识别 AI 文学"；②"流畅好读 = 文学质量"。**因此不能用"读起来顺"作为优化目标，也不能用检测器概率作为质量标准。**

### 0.2 本文的分析单位

汉语的"句子"边界是有争议的对象。本文采取三级单位，并在后续所有测量中显式区分：

| 单位 | 定义 | 用途 |
|---|---|---|
| **小句 (clause)** | 以谓词为核心的句法单位，可由逗号、分号或标点组边界切出；流水句中一个"句子"常含多个小句 | **句法指纹的主单位**（`syntax_fingerprint.md`） |
| **句 (sentence)** | 以句末标点（。？！……）为界的书写单位 | 句长分布、节奏测量 |
| **段落 / 语篇** | 自然段、场景、章 | 跨段落重复、信息释放、叙事节奏 |

理由：汉语流水句（"他没说话，站起来，走到窗边，把窗帘拉开一条缝"）在**书写层是一个句子**，但在**句法层是四个小句**。若以书写句为单位做模式统计，会把"四个小句各自复用同一模板"这一现象压缩成"一个长句"，从而系统性低估模板复用。沈家煊（2012）以"零句"为汉语基本单位、以"流水句"为汉语语篇常态的论证，是这一选择的语言学依据（`[K]` shen2012lingju）。**这是本项目第一个必须在代码层落实的方法论决定，不是可选项。**

## 1. 问题的定位：机械感从哪里来

### 1.1 三个已获实证的层次

**(a) 词汇层：过度表征 (overrepresentation)**
Juzek & Ward（2024）用一套可迁移的形式化方法，识别出科学摘要中**21 个焦点词**的出现频率上升很可能与 LLM 使用相关，并提出"词汇过度表征之谜"（`[E]` juzek2024delve）。中文对应现象在文学文本中表现为**套语密集**：同一批高概率搭配（如"嘴角勾起一抹弧度""空气仿佛凝固""心里五味杂陈"）在大量不同作品中反复出现。这属于"语料共现 + 采样高概率路径"的联合结果，而非单一原因。

**(b) 句法层：句法构造的多样性不足**
Guo, Shang & Clavel（2025）把语言多样性拆成 **lexical / syntactic / semantic** 三维，用统一框架基准测试多个前沿 LLM，并对**句法多样性**做了深入分析；结论是模型输出在多个维度上**未达到人类语言的多样性水平**，且模型的设计、训练与部署选择（含解码设置）会显著影响输出多样性；他们进一步在**故事生成**这一创造性任务上做了专门分析（`[E]` guo2025diversity）。这是本项目"句法层可测、可干预"的最直接依据。

**(c) 群体层：语言同质化 (homogenization)**
Sourati 等（2026, *Nature Human Behaviour*）报告"LLM 时代语言多样性景观的收缩"（`[E]` sourati2026shrinking）。这一层说明：即使单个文本看起来自然，**跨文本的分布**也可能变得单调——这正是"不同作品出现相似叙事组织方式"（研究问题 3）的宏观表现。

**(d) 创造性上限：不是"完全不行"，而是"顶尖层缺失"**
Bellemare-Pepin 等（2026, *Scientific Reports*）用发散联想任务（DAT）与多种创意写作任务（俳句、故事梗概、微型小说），在 10 万人规模数据上做同尺度比较：LLM 可**超过人类平均水平**、接近人类创意写作能力，但仍**低于人类高创意分段的均值**，且**被人类上半部分的聚合表现大幅超越**；同时，系统改变语言策略提示与 temperature 能带来**语义发散度的稳定提升**（`[E]` bellemare2026divergent）。这条证据同时支持两件事：①"多样性"是可以通过提示与超参改善的**可控量**；②提升有天花板，且**没有证据**表明提升发散度就等于提升文学质量。

### 1.2 为什么"机械感"是可以被语言学问切分的

机械感的直觉来源是**预测性过高**：读者能在读到句末前猜到句末。这与"高概率路径"同构，但**不能**简单等同于低困惑度——人类名家的文本也常常高度可预测（这是风格的一部分）。因此本项目的操作性定义是：

> **机械感 = 在给定体裁与上下文条件下，文本在"结构选择"上的条件熵显著低于同体裁人类分布，且这种降低不是由修辞意图（排比、反复、程式化）造成的。**

这个定义有两个好处：①它是**分布性**的，不依赖单句判断；②它把"修辞性重复"作为**例外项显式建模**，而不是当成噪声。

## 2. 现象分类（P1–P9）

每类给出：定义 → 中文实例（成对，A 为"模板化"、B 为"人类向"的写法；实例为本项目构造，仅用于说明，不作证据）→ 语言机制 → 可测代理 → 证据状态 → 归属模块。

### P1 词汇套语与搭配固化

- 定义：高频短语/搭配在单位字数内密度异常，且集中于少数语义场。
- 实例：A「她的眼中闪过一丝不易察觉的慌乱。」 / B「她低头去拢耳边的碎发，拢了两次，第二次手停在耳后没有放下来。」
- 机制：解码时高概率 n-gram 的自我强化；训练语料中"情绪—身体反应"的固定映射被固化为搭配。
- 代理：套语表命中率/千字；搭配新颖度（PMI 或与参考语料的搭配距离）；MTLD、Yule's K、distinct-n。
- 证据：`[E]` 过度表征现象（juzek2024delve）；词汇多样性维度（guo2025diversity）。**中文学套语表本身需要自建，无现成权威表**（`[H]`）。
- 模块：Lexical Analyzer。

### P2 抽象句法模板复用（核心问题）

- 定义：表面词汇不同，但**抽象句法结构**相同或高度相似。
- 实例：
  - A1「她没有回答，只是看着窗外。」
  - B1「他没有解释，只是低头整理衣袖。」
  - 共同骨架：`[SUBJ(代词/人名)] + [否定副词+动词] + 「，」 + [限定副词"只是"] + [动词短语]`，即**「否定—转折限定」小句对**模板。
- 机制：模型对"情感场景"的条件分布集中在少数几个高概率句法框架上；这些框架与语义功能（"以否定动作代替情绪陈述"）强绑定。
- 代理：骨架复用率、骨架分布熵、结构最近邻距离（TED/WL 核/path-Jaccard）、跨段落骨架聚类规模。
- 证据：`[E]` 句法多样性不足（guo2025diversity）；`[H]` "跨作品同骨架"的中文文学实证尚缺（见 `literature_review.md` §6 缺口）。
- 模块：Syntax Diversity Engine + Grammatical Fingerprint。

### P3 句首/句末位置模式固化

- 定义：小句起始成分（状语/时间/主语）与结尾成分（体标记、语气词、补语）的分布过于集中。
- 实例：A「清晨，阳光透过窗帘洒进来。」（时间状语+逗号开头的连续使用）/ B「窗帘没拉严，一道光斜在地板上。」
- 机制：汉语状语的句首位置是"话题/背景"的默认槽位；模型倾向于每段以背景状语开场（场景建立的高概率路径）。
- 代理：句首成分类型分布熵（POS/句法角色/词类）、句首 2-gram 重复率、句末 2-gram 重复率、段首句首成分的段间重复率。
- 证据：`[K]` 汉语话题优先与状语前置的语序事实（`[K]` chao1968, lv1979）；`[H]` 段首固化需自建基线与验证。
- 模块：Syntax Diversity Engine（位置子模块）。

### P4 小句切分与流水句节奏单一化

- 定义：小句长度、逗号间隔、句内小句数分布过于集中；缺乏"长句绵延 + 短句截断"的节奏对比。
- 实例：A（等长四拍）「他推开门，走进屋里，坐在椅子上，看着桌面。」/ B（节奏参差）「他推开门。屋里没人，桌上那只杯子还在冒气——他站着没动，很久。」
- 机制：汉语的"意合"允许极长的流水句，也允许极短的零句；节奏对比是汉语文学风格的核心手段之一（`[K]` shen2012lingju）。模型的长度分布受训练语料平均化与解码长度先验影响。
- 代理：小句长度分布的变异系数、句长分布偏度/峰度、句内小句数分布、句长序列的**停顿熵**（连续句长差分的熵）。
- 证据：`[H]` 需以人类多体裁语料建立基线；这是本项目最可能产出新实证的方向之一。
- 模块：Syntax Diversity Engine（节奏子模块）+ Narrative Analyzer。

### P5 虚词与体标记使用僵化

- 定义：`着/了/过`、`的/地/得`、`把/被/让/给` 的配比与分布异常；或"形合化"（连接词密度过高）。
- 实例：A「因为天气很冷，所以她把窗户关上了。」/ B「天冷，她把窗关严。」
- 机制：翻译体与教科书语体的"形合"倾向被大量语料携带；`把` 字句、`被` 字句的文体分布差异极大（政论/新闻 vs 小说/口语），模型会向训练分布均值回归。
- 代理：功能词频率向量、连词密度、把/被句占比、体标记与动词的搭配多样性、`的` 字结构长度分布。
- 证据：`[E]` Biber 特征体系里"语法特征"的组间差异（reinhart2025llmstyle 的核心正是 lexical/grammatical/rhetorical 三层特征）；`[K]` 汉语特殊句式的语体分布（`[K]` lv1979）。
- 模块：Stylometric Analyzer。

### P6 信息释放与叙事组织扁平化（过度解释）

- 定义：**先给情绪结论、再补细节**；段末总结句；每个场景以同一顺序（环境→动作→内心→总结）推进。
- 实例：A「她感到前所未有的孤独。窗外的雨下得很大，她的心情也像这雨一样沉重。」/ B「雨敲在空调外机上，一声一声，像有人在数。她把电视声音调大了一格。」
- 机制：训练目标鼓励"显式化语义关系"（把隐含关系写出来以降低损失），叠加对齐偏好"可理解性"，导致留白被填满。
- 代理：情绪词显式命名率、段末总结句比例（以"这就是/原来/或许/也许"类收束标记计）、场景功能序列的 n-gram 熵（同一序列重复）、"环境—动作—心理"三分结构的段落占比。
- 证据：`[H]` 强假说，需人评对照验证；`[E]` 相关线索：LLM 故事在基于 TTCT 的写作创造性测验（TTCW）上通过率显著低于职业作者（3–10 倍差距，chakrabarty2024art）。
- 模块：Narrative Analyzer + Literary Reviewer。

### P7 人物语言同质

- 定义：不同人物的台词在句长、用词、语气词、句法复杂度上缺少可分离的个体特征，无法"去掉说话人标签仍能分辨谁在说话"。
- 实例：A（三个角色同一腔调）「我不会放弃的，你要相信我。」/「我不会放弃的，你一定要相信我。」/「我绝不会放弃，请你相信我。」/ B（可分离）「信不信由你。」/「我试过了，真的，试过了。」/「放弃？我这个人，认死理。」
- 机制：对话被当作"信息传递"而非"人物行为"生成；缺少人物级 conditioning。
- 代理：人物语言分类器（只用该人物台词训练，留出验证）的准确率相对随机基线的提升；人物间特征距离（与人物内特征距离之比）；句长/句法复杂度/语气词的组间方差比（ANOVA F）。
- 证据：`[H]`；可借鉴的作者身份识别方法（同作者内文本可分性）迁移到人物层。
- 模块：Character Voice Engine。

### P8 修辞装置的程序化使用

- 定义：比喻结构单一（本体+「像/仿佛」+喻体三段式）、喻体语义场集中、通感/借代等复杂修辞几乎缺席。
- 实例：A「她的笑像春天的阳光。」/ B「她笑起来，左边嘴角比右边慢半拍。」
- 机制：明喻是最"安全"的修辞（不需要读者推理）；对齐偏好奖励"理解成本低"的表达。
- 代理：比喻触发词密度、喻体语义场分布熵、修辞类型覆盖度（明喻/暗喻/借代/通感/反讽的比例）、比喻的"跨域距离"（本体与喻体在词向量/义类体系中的距离）。
- 证据：`[H]`；`[E]` 旁证："AI 诗更受非专家偏好、其简单性被误读为人类性"（porter2024poetry）与"对齐导致表达简化"相容。
- 模块：Lexical Analyzer + Literary Reviewer。

### P9 描写抽象化与意象组织失调

任务书的「文学语言」方向里，有四项在前八类中只被间接覆盖：**具体/抽象描写比例、隐性情绪表达、文学留白、意象组织**。它们共享同一个可测量内核：**抽象层面与具体层面的配比，以及具体细节之间的关联方式**。因此合并为一类，但拆成四个可分别计数的子指标。

- 定义：把可感的具体细节（动作、器物、体感、环境）替换为**可直接命名的状态与判断**（"很难过""气氛尴尬""心里五味杂陈"），并使具体细节退化为**点缀**而非**承重**。
- 实例：A「她没说话，把手套一只一只叠好，压平，再放回口袋。」/ B「她沉默着，心里五味杂陈，气氛有些尴尬。」
- 四个子指标与代理量：
  1. **具象/抽象比**：可感名词（器物/身体部位/环境物）+ 具体动作动词的密度 ÷ 抽象状态词（情绪词、评价词、"氛围/气氛"类）的密度。`[H]`
  2. **隐性情绪表达**：情绪**不直接命名**而由动作/体感/环境承载的比例——可操作化为"情绪词出现处，其前后 2 句内是否有具体动作/体感描写"。`[H]`
  3. **留白**：关键信息（人物动机、关系转折、事件因果）的**显式陈述率**；反向指标是"每处情节转折后是否紧跟一句解释性总结"。P6 已经测了"段末总结率"，此处测的是**转折点后解释率**，两者不重复。`[H]`
  4. **意象组织**：同一意象（如"窗/雨/灯/手"）在篇内的**复现间隔与功能变化**——只复现不变功能 = 装饰性堆砌；复现且功能迁移（第一次是阻隔、第二次是出口）= 组织。可操作化为意象词的跨场景分布熵 + 功能标签序列的转移矩阵。`[H]`
- 机制：与 P1/P8 同源——抽象词是**低风险高概率**的续写选择（"难过"在任何上下文中都不会错），具体细节是**高风险低概率**的选择（"叠手套"只在特定人物上成立）。这解释了为什么对齐越强、抽象化越重：`[H]`，且与 `[E]` 的"对齐导致表达简化"方向一致。
- 与 P6 的区别（必须说清，否则会重复计数）：P6 测**信息释放的节奏**（什么时候说、说多少、是否总结）；P9 测**说的东西是具体的还是抽象的**。同一段可以"信息释放很克制"却"全部抽象"（只有氛围没有器物），也可以"信息很具体"却"过度解释"。二者正交。
- 反例警告：**抽象不是缺陷**。议论性散文、哲理小说、意识流都以抽象为骨架；沈从文的具体与张爱玲的抽象都是成熟的。因此 P9 的所有指标只能**与同体裁基线比**，且必须报告"抽象是否承担了功能"，不能报告"抽象比例高=差"。`[K]`
- 模块：Lexical Analyzer（子指标 1、2）+ Narrative Analyzer（3、4）+ Literary Reviewer。

| 编号 | 假说 | 机制说明 | 证据状态 | 可区分的预测 |
|---|---|---|---|---|
| M1 | 似然—典型性偏置 | 训练目标奖励高概率续写，导致语言"最可能的路径"被反复走 | `[E]` 退化/重复的经典证据（holtzman2020curious, welleck2020unlikelihood）；`[E]` 多样性不足（guo2025diversity） | 若成立：低 temperature 下模板复用率显著升高，升高 temperature 显著降低 |

## 4. 汉语特有的分析维度（本项目重点）

### 4.1 为什么"句子"必须先降级为"小句"

汉语缺乏形态标记，句子边界依赖标点与语气；流水句是汉语书面叙事的常态而非病句（`[K]` shen2012lingju）。工程含义：

1. 依存分析必须在**小句**层做，且允许"一句多根"（多小句并列）。主流工具（HanLP/LTP/Stanza）以书写句为输入，输出单根依存树——**直接使用会把多小句强行挂成一棵树，产生假边**（如把第二个小句的谓语挂到第一个小句的宾语上）。缓解方案见 `syntax_fingerprint.md` §2.1：先用标点+连词+主语重现做小句切分，再逐小句分析，最后在语篇层用"小句链"重建关系。
2. 零主语/话题链：汉语允许主语在话题链中持续省略（"他进了屋，[_] 脱了外套，[_] 坐下来"）。若不还原零形式，句法骨架会呈现"无主语"的畸形树，模板统计失真。方案：用话题链算法把相邻小句的空主语回指到最近的话题 NP，并在骨架中打 `ZERO→TOPIC` 标记（
   `syntax_fingerprint.md` §2.2）。
3. 汉语的"意合"使得**连接词密度**成为一个强文体变量：翻译体与政论文的形合连接词密度显著高于小说口语。这是 P5 的核心代理之一。

### 4.2 特殊句式配比作为文体指纹

以下句式在汉语中具有明确的语体/风格含义，应作为**显式特征**统计，而不是交给通用句法指标隐式吸收：

| 句式 | 结构标记 | 文体含义（需按体裁校准） | 提取方式 |
|---|---|---|---|
| 把字句 | 把 + NP + VP | 处置义，动作性强；口语叙事常见，文言少 | 依存标签 `ba`/`obj` + 词形「把」；LTP/HanLP 均有标记 |
| 被字句 | 被/让/叫/给 + NP + VP | 被动/受影响；书面语「被」与口语「让/叫」语体不同 | 词形 + `nsubj:pass`/`aux:pass` |
| 连动句 | V1 + V2 共享主语 | 动作链，汉语叙事核心句式 | 依存中两个动词同挂一个主语且顺序相邻 |
| 兼语句 | V1 + NP + V2（NP 兼语） | 使役/称谓；"让他走""称他为" | 依存中 NP 同时是 V1 的宾语与 V2 的主语 |
| 存现句 | 处所 + V + NP（"桌上放着一本书"） | 场景引入；AI 极偏好 | 依存 root 为存在动词 + 处所状语 |
| 名词谓语句 | NP + NP（"今天星期三"） | 口语、简洁 | 无动词谓语的句子 |
| 做主语句 | 主语从句（"他去不去无所谓"） | 书面、复杂 | 从句作 nsubj |

**关键点**：这些句式**人类也用**，且不同作家偏好不同（鲁迅的短句与被动、沈从文的长句与并列）。因此指标不是"用得多少"，而是"**配比是否落在体裁分布内、是否在段落间过度均匀**"。

### 4.3 音节节奏与四字格

汉语有音节计数传统（四字格、对偶、骈散）。模型倾向输出节奏均匀的短语（四字成语、双音节动词+双音节宾语）。可测代理：短语音节长度分布的熵、四字格密度、相邻小句音节数的相关性（人类叙事常用"长—短"交替制造停顿，AI 常呈高自相关）。

## 5. 反例与警告（防止研究变成偏见确认）

1. **人类文学的重合度可能很高**：章回体（"话说……""不在话下"）、武侠套路、网文"黄金三章"都是高度模板化的。若不做体裁条件化，指标会把整个网络文学判为"机械"。
2. **重复可以是艺术**：排比、反复、顶针、回环、叠字是汉语的核心修辞资源（"寻寻觅觅，冷冷清清，凄凄惨惨戚戚"）。判据不是"是否重复"，而是**重复是否承担了可辨识的修辞功能**（`syntax_fingerprint.md` §5 给出可执行判据）。
3. **简洁不等于机械，繁复不等于生动**。长度、复杂度指标必须双向解释：过短（电报体）与过长（从句套叠）都可能是问题。
4. **检测器不是质量尺**。Porter & Machery（2024）的实验已经表明人类判断会被"简单流畅"误导（`[E]` porter2024poetry）；Chakrabarty 等（2024）进一步表明，用 LLM 充当创造性评估者时，**没有任何 LLM 与专家评估呈正相关**（`[E]` chakrabarty2024art）。因此：LLM-as-judge 只能作为"守门员/回归测试"，不能作为文学质量的最终判据。
5. **"更像人"不是目标**。目标是"更好的文学"，二者可能冲突（`[E]` bellemare2026divergent 显示发散度可通过提示提升，但未证明文学质量随之提升）。

## 6. 从分类到控制变量：7 个可操作维度

| # | 维度 | 主指标 | 数据来源 | 干预点 |
|---|---|---|---|---|
| V1 | 词汇多样性 | MTLD / MATTR（窗口 50）/ MSTTR / HDD（近似）；Yule's K、distinct-2、套语密度**未实现** | 文本 | 提示词禁用表 + 候选重排 |
| V2 | 句法多样性 | 骨架分布熵 / 模板复用率 / 结构最近邻距离 | 依存分析 | 骨架抑制 + 候选重排 |
| V3 | 节奏 | 小句长度 CV / 句长偏度 / 停顿熵 | 分词+标点 | 场景级节奏规划 |
| V4 | 语体一致性 | 功能词向量 / 特殊句式配比 / 连接词密度 | 依存+词表 | 风格档位（profile） |
| V5 | 信息组织 | 情绪显式命名率 / 段末总结率 / 场景功能序列熵 | 规则+分类器 | 大纲中的信息释放表 |
| V6 | 人物语言 | 人物可分性（分类器准确率-基线） | 对话抽取 | 人物语言卡 |
| V7 | 修辞丰富度 | 修辞类型覆盖 / 喻体语义场熵 / 跨域距离 | 规则+词向量 | 修辞配额 |

**注意**：V1–V7 之间存在**冲突**（例如强行提高 V2 会降低 V4 的语体一致性，见 `generation_strategy.md` §5"过度多样化的代价"）。因此本项目不做"多指标同时最大化"，而是做**带约束的多目标优化**：以"落在体裁合理区间内"为约束，以"离体裁众数的距离"为惩罚，而非以"越极端越好"为目标。

1. 中文文学文本中，"骨架复用率"在人类 vs AI 上的**效应量**有多大？是否大于词汇层指标的效应量？（若句法层效应量不大，则 `syntax_fingerprint.md` 的价值主要在于**诊断与修复**，而非判别。）
