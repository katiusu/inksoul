# InkSoul 项目总览

## 1. 它是什么

InkSoul 是一个**面向 AI Agent 的中文文学创作增强插件**：在生成前给文体策略，在生成后给出
**可解释的句法/文体诊断**，并把诊断变成**局部、可回溯的修订建议**。

一句话区分它和常见工具：

| 常见「润色器 / 去 AI 味工具」 | InkSoul |
|---|---|
| 事后替换同义词、加形容词 | 先看句法骨架是否在重复，再决定改不改 |
| 输出「AI 概率 87%」 | 不输出任何概率值，只输出证据与位置 |
| 给一个综合分，诱导刷分 | 不合成总分，只给分项分布 + 问题清单 |
| 追求「每句都不同」 | 允许修辞性重复，只标「无意识模板复用」 |
| 需要大模型或 GPU 才能跑 | 分析层纯 CPU、零核心依赖，缺 jieba 也有中文报错 |

## 2. 要解决的具体问题

1. 句法结构复用：不同词、同一骨架（「他慢慢地推开了房门。」/「她轻轻地关上了窗户。」）
2. 句式、段落、表达方式同质化
3. 不同模型之间的文体差异（同一套阈值不适用于所有模型族）
4. 情绪表达过于直白或模式化（「心中五味杂陈」式套语）
5. 叙事节奏与语言缺乏变化（长短句分布、段落收束方式）
6. 人物语言缺少辨识度（对话与叙述比例、语气词/称呼习惯）
7. 生成过程中缺乏文体自我监控（只有事后润色）
8. 固定修辞和常见文学表达的滥用

**必须区分的三种重复**（这是本项目的核心判断，见 `docs/algorithm_design.md` §4）：

- 修辞性重复：排比、复调、首语重复、短句节拍 —— **不应报**
- 作者有意的结构复现：同一场景的呼应、章节间的回环 —— **降权**
- 无意识的机械复用：同模板换内容词、位置随机、间距均匀 —— **应报**

## 5. 快速开始

```bash
pip install -e .                 # 或安装 release/ 下的 wheel
inksoul doctor                   # 自检：Python / jieba / 后端 / 模型配置
inksoul analyze 我的稿子.txt      # 完整诊断
inksoul plan "雨夜，旧友重逢" --genre 小说   # 只要文体规划（离线可用）
```

需要生成正文时：配置 `~/.dsh/inksoul/config.json` 的 `model.base_url / api_key / model`，
再 `inksoul generate "..." --out draft.txt --report`。

## 6. 设计原则（写进代码的约束）

- **不把文学判断交给一个数字**：所有报告都是多指标并列。
- **没有依据就说没有**：无依存句法时，兼语/连动等判断标「低置信」，不伪造解析。
- **失败要能解释**：缺依赖、缺 Key、超长文本、API 不通，都给中文原因与下一步建议。
- **不替用户改风格**：修订只替换被点名的局部小句，长度异常即拒绝替换。
- **密钥不入日志、不入仓库**：`to_dict(redact=True)`、异常脱敏、测试断言。
