# InkSoul 发展计划 v2（2026-11-07）

> 依据：`research/papers/`（25 篇，L1 全文 12 篇）+ `docs/paper_alignment.md`（§1–§9 已落地记录）+ 当前代码 v0.4.2（210 tests）。
> 本文只写**能落到文件与数字上的**计划；纯观点集中在 §2 发散，筛选理由在 §2.2。

## 0. 一句话现状

引擎侧（测量、判定、闭环）已经比研究文档跑得快：markers 八族 + 人类分位数、短样本泊松、span 定位修订、多轮收敛都已落地；
**真正的短板在「判据可信度」与「改写保真度」**——我们能量出密度，但没测过「我们的闸门和人评到底多一致」，也没防住「改写把文章改薄」。

## 1. 从论文里搬什么（不是搬结论，是搬三种东西）

| 类型 | 例子 | 对本项目意味着 |
|---|---|---|
| **测量面** | Muñoz-Ortiz 依存弧长、Kendro 长度稳健词汇指标、Reinhart 特征组合 | 扩维度，但每加一维都要有「人类基线 + 分位数」 |
| **失败模式** | Chakrabarty：LLM 当评委与专家 κ≈0；Sourati：润色削平方差 21–50% 而语义余弦 >0.95 | 给每个自动判定配一个「它为什么会错」的护栏 |
| **判据设计** | LitBench：配对偏好 + 长度偏差披露；TTCW：14 条二元 rubric | 评测要可重复、可反驳，不追求单一分数 |

**已被论文纠正过的两次（方法论自证）**
1. IDIOM 族用 jieba `l` 标签把「捕捉到/脑海中」算四字格 → 改 `i` 且 ≥4 字，p99 从 19.00 降到 8.92。
2. HDD 旧实现画的是长度曲线（1x→10x: 0.979→0.618）→ 改为 McCarthy–Jarvis 口径（0.375→0.371）。

## 2. 发散：十个方向，先摊开再砍

### 2.1 候选池

| # | 方向 | 论文依据 | 价值 | 成本 | 依赖 |
|---|---|---|---|---|---|
| D1 | **改写局部复检**：新句仍命中同族就重采样/换模板 | LaSEr-Edit 约束校验 | 高（今天实测修订反而引入新命中，MTLD 216→95） | 低（纯 Python 复算 + 重试） | 无 |
| D2 | **restyle 保真护栏**：字数/语义/方差三保真 | Sourati 方差压缩、语义 >0.95 | 高（今天出现 1582→862 字塌缩） | 低 | 无 |
| D3 | **单一判定源**：gate 与 reviewer 共用同一份 markers 报告 | 工程一致性问题 | 高（今天出现「闸门 PASS + 9 条阻断」并存） | 低 | 无 |
| D4 | **配对评测集**：200 对「像人/不像人」，测闸门与人评一致率 + 长度偏差 | LitBench（RM 78%、Claude 73.1%） | 高（没有这个，一切阈值都是自说自话） | 中（要人工标注 200 对） | 人工时间 |
| D5 | **TTCW 中文 14 条**：只做评测维度，不做闸门 | Chakrabarty（专家 84.7% vs 最好模型 4.19/14） | 中高（能回答「改完真的更有创造性吗」） | 中（rubric 移植 + 评分开销） | 人工时间 |
| D6 | **模型家族基线**：同一套阈值不跨模型通用 | Reinhart（GPT-4o 63% vs Llama 141% 方向相反） | 中（换模型就得重标） | 中（每个家族 ≥50 篇样本） | 采样成本 |
| D7 | **跨章骨架预算**：多章写作时限制同一骨架复用 | Doshi（个体 novelty↑ 集体 diversity↓）、Sourati | 中（长篇连载特有） | 中 | 无 |
| D8 | **情节/母题多样性**：把 corpus 相似度扩到叙事结构层 | Xu 2025 PNAS（plot diversity 下降） | 中 | 高（结构标注） | 无 |
| D9 | **依存 Ω 最优性**：人类/模型差距最大的一维 | Muñoz-Ortiz | 低（本机 torch 装不上，缺 LAL） | 高 | PC 侧 |
| D10 | **检测器对照**：把 AIGT 检测器当测量边界，不当地面真值 | Li & Zhang 2025（微博 AIGT） | 低（我们明确不做 AI 概率） | 低 | 无 |

### 2.2 砍法（为什么只留 6 个）

- **D9 推迟**：aarch64 + 无 GPU + torch 轮子 486MB，换来的是一维指标，ROI 最差。
- **D10 不做**：与产品定位冲突（ADR-1 已定「不输出 AI 概率」），只保留「检测器不可当金标」的文档结论。
- **D8 暂缓**：需要人工标注情节单元，先做 D4 更划算。
- **留 D1 D2 D3**（今天实测暴露的三个硬缺陷，成本低、当天能验证）、**D4 D5**（构造判据可信度）、**D6 D7**（真实写作流程必需）。

## 4. 分阶段计划

### P0（本周，三个硬缺陷，每项都能当天验收）

**P0-1 改写局部复检（D1）**
- 位置：`src/inksoul/generation.py` `revise()`；每句改写后单独算该族标记数与句子质量，命中未降或有新命中 → 重采样一次（温度 0.6→0.8），仍不行就跳过该句并计入 `rejected`。
- 验收（v0.4.3 实测，stiff 夹具 1020 字 / 84 个叙述标记）：单轮下降 24%（3 轮闭环 84→24，降 71.4%）；新引入标记 2/27 ≈ 7%（旧版是负收益）；改写不合格 0 处。

**P0-2 restyle 保真护栏（D2）**
- 位置：`generation.restyle()`。三条同时满足才采纳：字数 85%–115%；字符级 3-gram 余弦 ≥0.60（纯 Python，无新依赖，作为「情节没被抽掉」的粗代理）；`length_dispersion.cv` 与 `mtld` 变化 ≤15%（防方差压缩）。
- 验收：今天的塌缩样例（1582→862 字）必须被拦下；正常重写不被误杀（拿 3 篇人类文本走一遍改造，采纳率 ≥2/3）。

**P0-3 单一判定源（D3）**
- 位置：`agent._grade` 与 `gate_text`。让 gate 直接消费 reviewer 已算好的 markers 报告（或反之只算一次），并在报告里写明「闸门判定口径」。
- 验收：同一文本上，`gate.status == PASS` 与「reviewer 中 marker 类 blocking == 0」永远同真同假；新增单测覆盖两者一致性。

### P1（两周，判据可信度）

**P1-1 配对评测集（D4）**
- 做法：从人类样本（815k 字）切 100 段，用真模型按同一 brief 生成 100 段，人工标注「更像人写的」；按 LitBench 方法报告：一致率、长度偏差（胜者更长比例）、按体裁分组。
- 验收：产出 `experiment/judge_agreement.md`，写明一致率与置信区间；**低于 65% 就调阈值，而不是宣布闸门有效**。

**P1-2 TTCW 中文 14 条（D5）**
- 只在 `evaluation` 路径启用（`inksoul analyze --rubric tt cw`），不进闸门、不参与选稿。
- 验收：与人工评分的一致性报告；作为「改写前后创造性是否下降」的回归指标。

### P2（一个月，真实写作流程）

- **D6 模型家族基线**：`data/marker_baseline_zh.json` 增 `by_model` 段，至少 DeepSeek 一家 ≥30 篇基线，报告注明来源。
- **D7 跨章骨架预算**：`agent` 写第 N 章时读前文 corpus 相似度，超过 0.6 就在提示里注入「避开这些骨架」。
- 顺手项：把 `docs/paper_alignment.md` 的 §1–§9 压成「结论 → 代码位置」索引表，避免文档继续长成日记。

## 5. 负向清单（明确不做）

1. 不做「AI 概率」输出，也不把第三方检测器当金标（ADR-1）。
2. 不做单一总分；选稿只看阻断数与硬指标（ADR-2）。
3. 不做「猜作者」式评测（Porter κ=0.005 已经证明它不携带质量信息）。
4. 不为追指标改写剧情：任何修订都必须保留原意（P0-2 的语义护栏就是这条的执行）。
5. 不在本机追神经依存/神经判官（torch 装不上的现实约束）。

## 6. 风险

| 风险 | 表现 | 缓解 |
|---|---|---|
| 阈值仍无外部标定 | 分位数来自单一人类样本（一部网文 542 块） | D4 的配对评测 + D6 换样本重标 |
| 修订越改越薄 | 今天的 MTLD 216→95 | P0-1 复检 + P0-2 方差保真 |
| 闸门与 reviewer 口径分叉 | 「PASS 但 9 条阻断」 | P0-3 单一判定源 |
| 中文 rubric 移植失效 | TTCW 的 14 条是英文文学语境 | P1-2 只当评测维度，先测一致性再决定是否扩用 |

#### D11（v0.5.0，已落地）：人类池距离，替代绝对密度判据

- 失败教训：v0.4.4 的 40 对配对评测把「绝对每千字密度」证伪（八族 AUC 0.29-0.52，闸门对 AI 零 FAIL）。
- 新口径：两本不同作者人类网文（240 段 900 字）六维 z 距离，越低越像人；P1-lite 验收 AUC **0.917**。
- 接入：analyze 输出池距与偏离维度；agent 的 rank 第四键为池距；闸门判定不变。
- 细节 docs/style_distance.md；池 src/inksoul/data/human_style_zh.json（mean 0.94 / p10 0.54 / p90 1.29）。
