# 已知局限（交付前必读）

本文件的目的：**不让使用者高估 InkSoul**。以下每条都是实际测量或代码事实，不是免责声明。

## 1. 指标阈值全部「未标定」

`cluster_sim_threshold=0.60`、`suspect_min_freq=3`、`para_spread≥2`、`gap_cv<0.5`、
`rate≥4%` 都是先验值。除 §3 的小样本外，没有大规模人工标注支撑。
**结论**：把输出当「线索」，不要当「判定」。

## 2. 没有真正的句法分析

默认后端是 jieba（词性 + 分词），**没有依存句法**。因此：

- 兼语（让他走）、连动（开门出去）、话题链、零主语，只能靠词表与位置启发式判断；
- 这类判断一律带 `confidence`，低置信时不应写进结论；
- spaCy 后端虽可载入（实测 12.4 s 载入 / 0.13 s 单句），但中文切分质量低于 jieba
  （如「窗关/上」被切开），**不推荐**作为默认。

## 3. 实验规模小，且对照不是真模型

`experiment/` 的「AI 端」是**模板拼接**样本（`gen_samples.py` 生成，非任何模型输出），
只代表「无意识模板复用」的上界。真实模型样本需要 API Key，本机没有，
所以**「指标 vs 真实模型」的外部效度未验证**。

已得到的结论仅限：修辞样本 0 误报 / 机械样本 100% 检出（n=4+4）；
人类语料阻断问题 0 条、模板样本平均 2 条（n=8+6）。样本小，不能外推。

## 4. 生成链路未对真实 API 验证

`generate()` 的成功/超时/429/坏 JSON/超长响应路径有单测（假 transport），
但**没有对 DeepSeek 真实接口做过端到端跑通**。首次真实使用请先：
`inksoul generate "测试" --target-chars 200 --report`。

## 5. 情绪与修辞识别是词表法

`RHETORIC_MARKERS`、情绪词表都是人工小词表，覆盖率有限；
讽刺、反语、克制的情绪表达**识别不到**，会出现「该报没报」。

## 6. 架构自检（实测）

`code_architecture_review`（root=`src/`）：17 个文件 / 8 个模块 / 11 条依赖边 /
**循环依赖 0**；无扇出热点（最大 `cli.py` 3）。超大模块 3 个：

| 文件 | 行数 | 说明 |
|---|---|---|
| `src/inksoul/fingerprint.py` | 565 | 指纹引擎全部算法 + 阈值，暂不拆（拆分会让常量与函数分离） |
| `src/inksoul/narrative.py` | 483 | 视角/场景/对话/信息密度四组词表驱动统计 |
| `src/inksoul/style.py` | 411 | 句长/词汇/词性/修辞/情绪词表 |

这三个都是「数据表 + 纯函数」的统计模块，按职责拆会打断对照阅读；
若后续继续增长，优先把词表移到 `data/` 并拆出 `metrics/` 子包。
模块依赖方向在 `docs/architecture.md` §7 给出；`analyzer.py` 是唯一装配点。

## 7. 长文本

- 单次上限 40 万字（`analysis.max_chars`），超出**报错**而非截断。
- 两两相似度（全局 `mean_pairwise_similarity`）与簇内变异（`variation`）都是 O(n²)：前者最多取 800 个小句、后者每簇最多取 60 个成员等距抽样，报告 `notes` 会写明抽样比例。
- 实测（重复句式文本）：4 万字 7.8 s、20 万字 9.1 s、40 万字 16.5 s；耗时不随字数爆炸，但抽样值只是估计。
- 未做流式分析；百万字作品请按卷分批。

## 8. 中文环境差异

- 繁体、竖排、明清白话（「说道」「恁地」）未专门适配；
- 中英混排会把英文词标成 `ENG`，骨架里按内容槽处理；
- 网络文学常见的「系统提示框」「弹幕体」会被当成正文分析，可能产生噪声。

## 9. 不做的事

- 不输出「AI 生成概率」，不用于 AI 检测规避；
- 不给综合评分，不做作者归属鉴定；
- 不自动改写整篇（只做局部替换，且长度异常即拒）；
- 不采集任何用户文本；分析全在本地内存完成，日志不含正文。

## 6. 2026-11-06 新增的未标定阈值与后端限制

| 项 | 值 | 状态 | 说明 |
|---|---|---|---|
| `corpus.NEAR_IDENTICAL_SIM` | 0.90 | 未标定 | 标「几乎同构」用的骨架余弦阈值；实测模板 0.902（同源上限）与人类 ≤0.21，中间地带未知 |
| `corpus.MIN_CLAUSES_PER_WORK` | 20 | 未标定 | 少于 20 小句的作品不参与两两比较（骨架分布不稳） |
| `diversity.MID_LEN_LO/HI` | 10 / 30 | 未标定 | 「中等长度占比」的区间，取英文新闻分布，中文需重标 |
| `dependency.BIN_MIN_SENTENCES` | 10 | 未标定 | 句长分箱内少于 10 句标 `low_sample` |

依赖层（`dependency`）**要求 `Document.has_dependency=True`**，而默认后端 jieba 没有依存句法：
用 jieba 时该字段是占位（`{"unavailable": true, ...}`），不是零值。要拿到真实弧长/依存关系分布需
`backend="spacy"`（代价：12.4s 载入、0.13s 单句，见 ADR-3）。**Ω 最优性指标未实现**。

跨文本相似度是**骨架分布余弦，不是语义 embedding**：能测「文体同构」，测不到「题材重复」；
同体裁、同作者、同题材料都会推高它，不能单凭数值判 AI。

## 7. 第二批新增阈值（同样未标定）

| 项 | 值 | 说明 |
|---|---|---|
| `lexical.MATTR_WINDOW` | 50 | 滑窗大小，Covington & McFall 原文默认 |
| `lexical.MSTTR_SEGMENT` | 100 | 分段大小 |
| `lexical.MTLD_TTR` | 0.72 | MTLD 阈值，换阈值整体平移 |
| `lexical.HDD_SAMPLE` | 42 | 超几何抽样规模（固定值，别改） |
| `lexical.MIN_TOKENS` | 50 | 低于此词数只报 TTR |
| `stylometry.N_FEATURES` | 100 | Delta 的高频字数（Burrows 原文 100–500） |
| `stylometry.MIN_CHARS` | 200 | 参与 Delta 的最少字符数 |

**Delta 的 z 标准化在本比较集内进行 ⇒ 只能同集比较，不能跨语料比绝对数值**（实测：
模板组内 1.302、人类组内 1.197，方向与 O'Sullivan 相反；合并 14 篇后 14/14 最近邻同组，方向恢复）。
