# 算法设计（含必答六问）

> 任务书第五节要求每个核心算法说明：理论依据、输入输出、原理、复杂度、可能误判、测试方法、
> 是否适合实际创作。本文按此结构写。**所有阈值均为未标定默认值**，标定方法见 §7。

## 1. 归一化（normalizer.py）

- **理论依据**：句法相似性应建立在词类与功能词之上，而不是词形（Sinclair 的词汇语法观；
  计算文体学中 POS n-gram 是标准特征）。
- **输入/输出**：`Token(word, pos, flag)` → `Token.norm`（受控符号）/`Token.sub`（细分）。
- **原理**：jieba 的 `flag` 先映射到基础符号（n→N、v→V、d→ADV …），再跑三遍消歧：
  1. 规则层：`把/被` 介词化、动词被标 n/s 的纠偏（见 `data/verbs_zh.txt`）、状态词 z→A、
     单字处所 `窗/门/屋` 在介词后→LOC。
  2. 第二遍：`只是/不过` 看右邻（动词/形容词/副词→ADV_LIM，否则→CONJ_LIMIT）。
  3. 第三遍：`没有/没` 若已判 NEG 且后接标点或名词性成分→改判 V（「什么也没有。」）。
- **复杂度**：O(n)（三遍线性扫描）。
- **可能误判**：jieba 词性本身不可靠（实测 `把门` 合并为名词、`关上` 标 s）；
  `_verb_lexicon` 只覆盖常用叙事动词，冷僻动词仍可能被误判。**一律通过 `confidence` 标注**。
- **测试**：`tests/test_normalizer.py`（9 个用例，覆盖否定词/句末「没有」谓词化/把字/被字/状语「地」/并行小句同骨架）。
- **适用性**：作为「骨架输入」够用；**不能**据此声称做了句法分析。

## 2. 句法指纹（fingerprint.py）

### 2.1 骨架与相似度

- **理论依据**：结构相似 ≈ 在功能锚点不变的前提下，内容槽可替换。编辑距离在序列上度量
  「最少需要多少次替换/增删才能变成对方」，因此可直接映射为「结构是否同构」。
- **输入/输出**：`Clause.skel` → `similarity(a, b) ∈ [0,1]`。
- **原理**：

  ```
  cost(替换) = 1.0  若任一侧是功能锚点（NEG/ADV_LIM/CONJ_*/PREP_*/DE_*/ASP/DIR）
             = 0.15 若两侧都是内容类且同类（V↔V、N↔LOC 视为同类 NP 槽）
             = 0.25 若两侧都是内容类但异类
  cost(增删) = 1.0（锚点）/ 内容类按 1.0
  similarity = 1 - distance / (max(len_a, len_b) × 1.0)
  ```

  例：`他/PRON 慢慢地/ADV 推开/V 了/ASP 房门/N 。/P` vs
  `她/PRON 轻轻地/ADV 关上/V 了/ASP 窗户/N 。/P` → 仅两个内容槽替换 → 相似度 ≈ 1 - 0.3/6 ≈ 0.95。
- **复杂度**：O(|a|·|b|)，小句长度中位数 < 20，实测单篇 344 小句 < 0.2 s。
- **可能误判**：连续动作被切碎、专名被切成单字（`孔乙己` → `孔/乙/己` 时骨架失真）；
  短句（≤3 符号）区分度低，已用 `Cluster.informative` 过滤。
- **测试**：`tests/test_fingerprint.py`（12 个用例：并行对高相似、无关对不相似、零主语不并簇、把字句不并簇、距离对称、复用率边界、跨段嫌疑、空文本）。

### 2.2 结构簇

- **原理**：① 按骨架串精确分组建簇；② 组间与**代表元**（组内最长成员）比较：
  `similarity ≥ 0.60` 且**槽位模板一致**才归并。
  槽位模板 = 内容槽折成 `*`，删去标点与 ASP/DE，连续 `*` 压成一个；
  若模板里没有任何锚点（纯 `*`），还要求长度相同、首位粗类相同。
- **为什么不用并查集**：链式合并会把 A≈B、B≈C 串成一个巨簇（实测 107 字短文并成 1 簇，
  复用率虚高到 79%）。星形归并 + 模板约束把「传递性」截断，结果可复现、可解释。
- **复杂度**：O(G × K × L²)，G 为精确组数、K 为簇数；簇内变异 O(k²) 与全局两两相似度 O(n²)
  都按固定上限等距抽样（`VARIATION_SAMPLE=60`、`PAIR_SAMPLE_CLAUSES=800`）。实测 4 万字 7.8 s、
  20 万字 9.1 s、40 万字（5.3 万小句）16.5 s。
- **测试**：`tests/test_fingerprint.py` 的 `test_zero_subject_not_merged` / `test_ba_vs_normal_not_merged` /
`test_suspect_needs_cross_paragraph`；另有孔乙己回归（修复前 38 条 → 修复后 0 条，见 `experiment/reports/report.md`）。

### 2.3 复用率与熵

- `reuse_rate = Σ_{freq≥2} freq / clause_count`（被复用的小句占比）
- `pattern_entropy = -Σ p log2 p`；`pattern_entropy_norm = entropy / log2(distinct)`（0–1）
- **注意**：复用率高不必然是坏事（修辞性重复也会高），必须结合 §4 的 J1–J3。

## 3. 分布类指标（diversity / style / narrative）

全部是描述统计，不做判定：

| 模块 | 关键指标 |
|---|---|
| diversity | 相邻相似度均值、高相似占比、段内重复率、跨段复用率、句首重复、句长/小句长分箱 |
| style | 句长均值/中位数/标准差、长短句比、TTR、MTLD-like、词性分布、虚词占比、对话占比、修辞标记计数、情绪词命中、段落节奏 |
| narrative | 视角（人称代词比例 + 对话内比例，带 confidence）、场景转换计数、对话节拍、言语动词、信息密度（每段新信息小句占比） |

**边界**：视角/场景识别基于词表与代词分布，**不是**篇章解析；`confidence` 低时不可当结论用。

## 4. 机械复用判定（reviewer.py + fingerprint._judge）

三组判据（J1–J3）给出**可解释证据**，不是黑箱打分：

| 判据 | 定义 | 倾向 |
|---|---|---|
| J1 位置 | 簇内小句在全文中的相对位置标准差 `≤ 0.15` | 固定（修辞）↔ 随机（模板） |
| J2 变异 | 簇内骨架编辑距离的标准差 `≤ 0.15` | 极小 = 换内容词 → 模板嫌疑 |
| J3 标记 | 簇内出现 `RHETORIC_MARKERS`（如同/仿佛/一遍又一遍…） | 修辞性重复 |

判定：`freq ≥ 3` 且 `para_spread ≥ 2` 且 `gap_cv < 0.5` 且 `freq/clauses ≥ 4%` → 嫌疑；
J3 命中且 J2 极小 → **豁免**（`exempted`，仍然列出以供人工判断）。

**可能误判**（已实测）：旧版把「多是短衣帮 / 温两碗酒 / 换一碗饭吃」并为一簇（`NUM V N V P`，
freq=9），在《孔乙己》上报 38 条 → 修复后 0 条。教训：**同符号数不等于同结构**。

**测试**：`tests/test_reviewer.py`；实验 E（修辞误报率 0.0、机械检出率 1.0，n=4+4，样本极小）。

## 5. 生成控制（generation.py）

- **理论依据**：prompt 层只能改「均值」，改不了「方差」；有效控制点在**生成之间**（多候选择一）
  与**生成之后**（局部修订）。见 `docs/generation_strategy.md`。
- **原理**：规划 → 多候选（不同温度）→ 用阻断级问题数择稿 → 逐条局部修订 → 复核。
- **复杂度**：O(candidates × 单次生成) + O(问题数 × 单次改写)，约束「每轮 ≤ 8 条」。
- **可能误判**：模型改写可能引入新问题；因此修订后**必须重跑 analyze**，且长度异常即拒绝替换。
- **测试**：`tests/test_generation.py` 用假 transport 覆盖成功/超时/坏 JSON/长度越界。
- **适用性**：**未对真实 API 端到端验证**（本机无 Key），这是交付物中最大的未验证项。

## 6. 体裁基线（baseline）

- `Baseline(genre, version, n_clauses, patterns, tau, source)`：某体裁的骨架分布。
- `coverage` = 文本中落在基线高频骨架上的小句占比；`novelty = 1 - coverage`。
- **不合成总分**：coverage 高说明「像这个体裁」，不等于「写得好」。
- **版本化**：`NORM_TABLE_VERSION` 变更即需重建基线。

## 7. 阈值标定计划（未完成）

1. 人工标注 ≥ 200 条小句对（同构/不同构），扫 `sim_threshold ∈ [0.5, 0.9]`，取 F1 最大点。
2. 标注 ≥ 50 篇（人类/AI/模板），以「专家是否认为存在机械复用」为金标，
   拟合 `freq / para_spread / gap_cv / rate` 的判定边界。
3. 报告 AUC + 置信区间，**不**用单一准确率掩盖类别不平衡。
4. 标定结果写回 `fingerprint.py` 顶部常量并更新 `experiment/results/`。
