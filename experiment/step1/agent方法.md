# agent 写出自然人类语言：方法

> 依据：本项目三轮实测（规则后编辑不开火、指标表进 prompt 更差、千字尺子噪声大于信号）+ 本地文献（指令调优是 AI 味主因、无统一"更人性"方向、过约束产生生硬）。

## 三条铁律

1. **具体性只能来自材料，不能来自模型。** 模型自己想，只能想到平均值。
2. **不做全局重写。** 全篇重写必然回均值；只改被明确指出的那一处，改完二选一，不融合。
3. **不把统计指标写进生成提示。** 指标只用于事后判断，不用于生成。风格靠示例锚（给原文），不靠形容词表。

## 七步循环（每节跑一遍）

### 0. 材料卡（人定，agent 只负责提问补齐）

agent 不许自己编材料。缺一项就问作者，问不出来就用"不知道"占位，不许糊。

卡面固定七项：
- 谁：姓名、年纪、职业、身上一个只有他会做的动作
- 在哪：具体地点（街名/房号/工位），一个不体面的细节
- 何时：几点、天气、身上什么味道
- 此刻要什么：一件今天必须办成的事
- 怕什么：一件不能被知道的事
- 这一场必须发生三件事：写死三条，缺一不算完成
- 他绝不会说的三句话：负空间，比正面要求更管用
- 一个具体数字或物件：全篇复现三次，叫法不许换

### 1. 锚段（示例，不是分析）

从目标作者原文里挑 2–3 段同题材同人称的段落（合计 600–1200 字），原样放进上下文，**不加任何分析、不列特征、不提指标**。只加一句交代："参考它的句子怎么走，不要参考它写了什么。"

### 2. 事实表（先建，每节更新）

四栏，每节写完回写：
- 人物称呼（谁叫谁什么，变过一次就记下变了）
- 物件的叫法（红绳就是红绳，不许同义替换）
- 已发生（按节号一句话）
- 已埋未兑现（伏笔清单，兑现一条划一条）

事实表就是 agent 的记忆，模型自己是没有的。

### 3. 逐节写（一次一节，800–1500 字）

单节输入只有五样：材料卡 + 锚段 + 事实表 + 本节任务一行 + 上一节最后 200 字。
不给全篇大纲之外的东西，不给风格形容词，不给"写得像人一点"。

### 4. 自读（写完立刻做，换读者视角）

同一个 agent 通读本节，**只许标 1–3 处**，每处必须带位置和一句理由，理由只能从这三个里选：
- 这一句在替我解释（人物已经用动作说过了）
- 这一句是空的（换个词意思不变，说明它没信息）
- 这一句多余（删掉不影响任何事）

禁止使用的判据：AI 味、不够自然、可以更生动。说不清具体位置的，不许改。

### 5. 定点改

只改标出的那 1–3 处，单句长度浮动不超过 ±15%，**不许顺手重写整段**。
每处改完，把旧句和新句并排看，二选一（不做融合版），选更像"有人这么说话"的那句。

### 6. 事实表回写

本节新增或改动的事实写回去；如果本节改了前文设定，标注冲突点，交给作者决定。

### 7. 连读（全篇写完一次）

只查跨节不一致：称呼、物件叫法、时间线、伏笔没兑现。查出问题只改那一处，不重写章节。

## 禁止清单（每条都有实测或文献依据）

- 全篇重写、整段润色
- 把句长分布、复用率、模具配额写进生成提示
- 用温度造多样性
- 用模型当裁判打分（实测接近随机）
- 用"你要写得像人"这类指令
- 一次生成一万字

## 验收方式

不看指标，看两版：同一份大纲，一版一次成稿，一版走七步循环，**同一个人读**，只回答三个问题：
1. 哪一版里有一句让你停了一下？
2. 哪一版的人物说话前后是一个人？
3. 哪一版你读到一半想翻回去看前面？

三项里赢两项算方法成立。
